# TestLCD — проверка кириллицы на LCD1602A / LCD2004

Отдельный диагностический скеч. Не съдържа управление на енкодер, двигатели или подаване.

## Файлове
- `TestLCD.ino` — тестова програма.
- `LiquidCrystalRus.cpp` и `LiquidCrystalRus.h` — копие на библиотеката от корена на хранилището.

## Свързване
Същите пинове като основния проект:
- RS → D8
- E → D9
- D4 → D10
- D5 → D11
- D6 → D12
- D7 → D13

## Стартиране
Отвори папката `TestLCD` като Arduino IDE sketch folder и качи `TestLCD.ino` на Arduino Mega 2560.

Тестът последователно показва главни и малки руски букви. За LCD1602A се използва `lcd.begin(16, 2)`. При LCD2004 промени само размера на дисплея на `lcd.begin(20, 4)`, ако искаш да го провериш.

**Забележка:** тестът използва библиотеката в текущия ѝ вид. Не прави автоматично промени по оригиналната библиотека или основния проект.
